# 05-1. 배열 이해하기

자바스크립트에서 배열은 Array 클래스의 인스턴스이다.
```js
let 배열 이름 = new Array(배열 길이)
```
```js
let array = new Array
array.push(1); array.push(2); array.push(3)
console.log(array) // [1, 2, 3]
```

## [] 단축 구문
앞서 배열을 만드는 방식은 번거롭기 때문에 자바스크립트는 `[]`라는 단축 구문을 제공한다.
```js
let numbers = [1, 2, 3]
```

## 자바스크립트에서 배열은 객체다
- 자바스크립트에서 배열은 다른 언어와 다르게 객체이다.
    - 배열은 Array 클래스의 인스턴스
    - 클래스의 인스턴스 = 객체

## 배열의 타입
타입스크립트에서 배열의 타입은 `아이템 타입[]` 이다.<br>
다음은 배열에 타입 주석을 붙인 예시 이다.
```ts
let numArray: number[] = [1, 2, 3]
let strArray: string[] = ['Hello', 'World']
```

## 문자열과 배열 간 변환
- 어떤 프로그래밍 언어는 문자열(string)을 문자(character)들의 배열(array)로 간주한다. 그러나 타입스크립트에서는 문자 타입은 없고 문자열의 내용 또한 변경할 수 없다.
- 이런 특징으로 문자열을 가공하려면 문자열을 배열로 전환해야 한다. 보통 문자열을 배열로 전환할 때는 String 클래스의 split 메서드를 사용한다.
    - split 메서드 : 문자로 쪼개는 기준인 구분자를 입력받아 문자열을 string[] 배열로 반환
```ts
split(구분자: string): string[]
```
- string[] 타입 배열을 다시 string 타입으로 변환하려면 Array 클래스의 join 메서드를 사용한다.
    - join 메서드 : 배열의 문자열과 구분자를 결합한 새 문자열을 반환
```ts
join(구분자: string): string
```

## 인덱스 연산자
배열의 특정 위치에 있는 아이템을 얻고자 할 때 인덱스 연산자(index operator)를 사용한다.
```ts
const numbers: number[] = [1, 2, 3, 4, 5]
numbers[0]
```

## 배열의 비구조화 할당
객체 뿐만 아니라 배열에도 [비구조화 할당](../chapter01/ch01-2.md#esnext-주요-문법)을 적용할 수 있다.<br>
객체와 달리 배열에는 `[]` 기호를 사용한다.
```ts
let array: number[] = [1, 2, 3, 4, 5]
let [first, second, third, ...rest] = array
console.log(first, send, third, rest) // 1 2 3 [4, 5]
```

## for...in 문
- ESNext 자바스크립트와 타입스크립트는 for 문을 쉽게 사용하도록 for...in 문을 제공한다.
- 객체를 대상으로 사용하지만, 배열도 객체이므로 배열에도 사용할 수 있다.
    - 배열을 사용하면 인덱스로 순회한다.
```ts
let names = ['Jack', 'Jane', 'Steve']

for(let index in names) {
    const name = names[index]
    console.log(`[${index}]: ${name}`)
}
```
객체를 사용할 때는 객체의 속성을 대상으로 순회한다.
```ts
let jack = { name: 'Jack', age: 32 }

for (let property in jack) {
    console.log(`${property}: ${jack[property]}`) // name: Jack age: 32
}
```

## for...of 문
- ESNext 자바스크립트와 타입스트립트는 사용법이 약간 다른 for...of 문도 제공한다.
- 배열의 경우 for...in 문은 인덱스를 대상으로 순회하지만, for...of 문은 아이템 값을 대상으로 순회한다.
```ts
for (let name of ['Jack', 'Jane', 'Steve'])
    console.log(name) // Jack Jane Steve
```

## 제네릭 방식 타입
- 타입을 T와 같은 일종의 변수(타입 변수)로 취급하는 것을 제네릭(generics) 타입이라고 한다.
- 다음은 자바스크립트 함수에 타입스크립트의 제네릭 타입을 적용한 예시 이다. 컴파일러가 T의 의미를 알 수 있어야, 즉 T가 타입 변수(type variable)라고 알리기 위해 `<T>`를 추가한다.
```ts
const arrayLength = <T>(array: T[]): number => array.length
```

## 제네릭 함수의 타입 추론
- 제네릭 형태로 구현된 함수는 원칙적으로는 3행처럼 타입 변수를 명시해 주어야 한다.
- 하지만 번거롭기 때문에 타입스크립트는 4행처럼 타입 변수 부분을 생략할 수 있게 한다. 타입스크립트는 타입 변수가 생략된 제네릭 함수를 만나면 타입 추론을 통해 생략된 타입을 찾아낸다.
```ts
const identity = <T>(n: T): T => n

identity<boolean>(true)
identity(true)
```

## 제네릭 함수의 함수 시그니처
- 4장에서 함수의 타입, 즉 [함수 시그니처](../chapter04/ch04-1.md#함수-시그니처-function-signature)에 대해 알아보았다.
- 타입스크립트는 어떤 경우 함수 시그니처의 매개변수 부분에 변수 이름을 기입하라고 요구한다.
    - 예시의 normal 함수의 cb 매개변수에 함수 시그니처를 사용했다.
    - 그러나 error 함수는 오류가 발생한다.
    - fixed 함수처럼 타입스크립트가 해석하지 못하는 부분에 변수를 삽입하고 그 변수에 타입을 명시해 해결해야 한다.
```ts
const normal = (cb: (number) => number): void => {}
const error = (cb: (number, number?) => number): void => {} // 'number' 식별자가 중복되었습니다.
const fixed = (cb: (a: number, number?) => number): void => {}
```
제네릭 타입의 함수에서도 같은 문제가 발생하는데, 해결 방법은 fixed 함수에서와 같다.
```ts
const f = <T>(cb: (arg: T, i?: number) => number): void => {}
```

## 전개 연산자
`...`을 나타내는 [전개 연산자(spread operator)](../chapter03/ch03-4.md#전개-연산자-spread-operator)는 배열에도 적용할 수 있다.
```ts
let array1: number[] = [1]
let array2: number[] = [2, 3]

let mergedArray: number[] = [...array1, ...array2, 4]
console.log(mergedArray) // [1, 2, 3, 4]
```
