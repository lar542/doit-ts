# 10-2. 제네릭 타입 제약

제네릭 타입 제약(generic type constraint) : 타입 변수에 적용할 수 있는 타입의 범위를 한정하는 기능
```ts
<최종 타입1 extend 타입1, 최종 타입2 extend 타입2>(a: 최종 타입1, b: 최종 타입2, ...) {}
```
```ts
interface IValuable<T> {
    value: T
}
class Valuable<T> implements IValuable<T> {
    constructor(public value: T) {}
}

// 제네릭 타입 제약 구문을 사용한 제네릭 함수
const printValueT = <Q, T extends IValuable<Q>>(o: T): void => console.log(o.value)

// 이런식으로 구현하면 안 된다. 매개변수 o의 T 입장에서 타입 T는 IValuable<T> 이므로, 타입스크립트는 IValuable <IValuable<T>>로 해석하기 때문이다.
// const printValueT = <T extends IValuable<T>>(o: T): void => console.log(o.value)

// printValue의 매개변수 타입을 어떤 방식으로 제약하느냐만 다를 뿐 사용법은 동일
 printValueT(new Valuable(1))
 printValueT({ value: 1 })
```

## new 타입 제약
- 팩토리 함수(factory function) : `new` 연산자를 사용해 객체를 생성하는 기능을 하는 함수
- 보통 팩토리 함수는 객체를 생성하는 방법이 복잡할 때 이를 단순화하는 목적으로 구현
- 다음의 매개변수 type은 실제로는 '타입'이다.
- 따라서 type 변수의 타입 주석으로 명시한 T는 '타입의 타입'에 해당한다.
- 하지만 타입스크립트 컴파일러는 '타입의 타입'을 허용하지 않아서 오류가 발생한다.
```ts
const create = <T>(type: T): T => new type()
```

다음은 다음은 '타입의 타입'을 타입스크립트 구문으로 표현
```ts
const create = <T extends {new(): T}>(type: T): T => new type()
```

create 함수의 타입 제약 구문을 중괄호를 없앤 간결한 문법으로 표현
```ts
const create = <T>(type: new() => T): T => new type()
```

- 결론적으로, `{new(): T}`와 `new() => T`는 같은 의미이다.
- new 연산자를 type에 적용하면서 type의 생성자 쪽으로 매개변수를 전달해야 할 때 다음처럼 `new(...args)` 구문을 사용한다.
```ts
const create = <T>(type: {new(...args): T}, ...args): T => new type(...args)
```

```ts
class Point {constructor(public x: number, public y: number) {}}

[
    create(Date),
    create(Point, 0, 0)
]
.forEach(s => console.log(s))
```

## 인덱스 타입 제약
인덱스 타입 제약 (index type constraint) : 다음처럼 `keyof T` 형태로 타입 제약을 설정할 수 있게 지원
```ts
<T, K extends keyof T>
```
```ts
const obj = { name: 'Jane', age: 22, city: 'Seoul', country: 'Korea' }

const pick = (obj, keys) => keys.map(key => ({ [key]: obj[key] })).reduce((result, value) => ({ ...result, ...value }), {})

console.log(
    pick(obj, ['name', 'age']),
    pick(obj, ['nam', 'agge']) // 오타 방지를 목적으로 keyof T 형태의 인덱스 타입 제약을 지원
)
```

- 다음은 K 타입에 타입 제약을 설정하지 않아서 오류 발생.
- 타입 K가 T의 속성 이름(key)라는 것을 알려줘야 하므로, 타입스크립트의 인덱스 타입 제약을 적용해야 한다.
```ts
const pick = <T, K>(obj: T, keys: K[]) => keys.map(key => ({ [key]: obj[key] })).reduce((result, value) => ({ ...result, ...value }), {})
```

다음은 `keyof T` 구문으로 타입 K가 타입 T의 속성 이름이라고 타입 제약을 설정
```ts
const pick = <T, K extends keyof T>(obj: T, keys: K[]) => keys.map(key => ({ [key]: obj[key] })).reduce((result, value) => ({ ...result, ...value }), {})

console.log(
    pick3(obj, ['name', 'age']),
    pick3(obj, ['nam', 'agge']) // 컴파일하지 않아도 코드 작성 시점에 탐지 가능
)
```
