# 10-4. 타입 가드

## instanceof 연산자
```ts
class Bird {
    fly() { console.log(`I'm flying.`) }
}
class Fish {
    swim() { console.log(`I'm swimming.`) }
}

// 자바스크립트가 제공하는 instanceof 연산자
const flyOrSwim = (o: Bird | Fish): void => {
    if (o instanceof Bird) {
        (o as Bird).fly()
    }
    else if (o instanceof Fish) {
        (<Fish> o).swim()
    }
}
```

## 타입 가드
- 타입스크립트에서 instanceof 연산자는 자바스크립트와 다르게 '타입 가드(type guard)' 기능이 있다.
    - 타입 가드 : 타입을 변환하지 않은 코드 때문에 프로그램이 비정상 종료되는 상황을 보호해 준다는 의미
- 따라서 instanceof 연산자의 타입 가드 기능을 사용해 타입을 전환하지 않고 사용할 수 있다.
```ts
const flyOrSwim2 = (o: Bird | Fish): void => {
    if (o instanceof Bird) {
        o.fly()
    }
    else if (o instanceof Fish) {
        o.swim()
    }
}
```

## is 연산자를 활용한 사용자 정의 타입 가드 함수 제작
함수 반환 타입에 `is` 연산자를 사용해 사용자 정의 타입 가드 함수 구현
```ts
const isFlyable = (o: Bird | Fish): o is Bird => {
    return o instanceof Bird
}
const isSwimmable = (o: Bird | Fish): o is Fish => {
    return o instanceof Fish
}

const flyOrSwim3 = (o: Bird | Fish): void => {
    if (isFlyable(o)) o.fly()
    else if (isSwimmable(o)) o.swim()
}
```
