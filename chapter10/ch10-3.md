# 10-3. 대수 데이터 타입

- ADT : 함수형 언어에서 대수 데이터 타입(algebraic data type)을 의미
- 타입스크립트에서 대수 데이터 타입은 합집합 타입(union type)과 교집합 타입(intersection type)이 있다.

## 합집합 타입
'or'의 의미인 기호 `|`로 다양한 타입을 연결해서 만든 타입
```ts
type NumberOrString = number | string
let ns: NumberOrString = 1
ns = 'hello'
```

## 교집합 타입
- 'and'의 의미인 기호 `&`로 다양한 타입을 연결해서 만든 타입
- 대표적인 예로 1개의 객체를 통합해서 새로운 객체를 만드는 것
```ts
const mergeObjects = <T, U>(a: T, b: U): T & U => ({ ...a, ...b })
```
```ts
type INameable = { name: string }
type IAgeable = { age: number }

const nameAndAge: INameable & IAgeable = mergeObjects({ name: 'Jack' }, { age: 32 })
```
