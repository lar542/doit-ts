# 10-6. nullable 타입과 프로그램 안전성

## nullable 타입이란?
- 자바스크립트와 타입스크립트는 변수를 초기화하지 않으면 `undefined`를 기본으로 지정한다.
- 그런데 `null`은 자바스크립트와 타입스크립트에서 사실상 `undefined`와 같은 의미인데, 타입스크립트에서 `undefined` 값의 타입은 `undefined`이고, `null` 값의 타입은 `null` 이니 이 둘은 사실상 같은 것으로 호환된다.
- `undefined`와 `null` 타입을 `nullable` 타입이라고 한다.
```ts
type nullable = undefined | null
const nullable: nullable = undefined
```

## 옵션 체이닝 연산자
- 그런데 이런 `nullable` 타입은 프로그램을 비정상 종료시키는 주요 원인이 되는데 이를 방지하기 위한 '옵션 체이닝(optional chaining)' 연산자와 '널 병합 연산자(nullish coalescing opertor)'가 있다.
- 자바스크립트는 두 연산자를 표준으로 채택했고, 타입스크립트도 지원한다.
```ts
let person: IPerson
console.log(person.name) // 변수를 초기화하지 않아서 런타임 오류 발생
```

```ts
let person: IPerson
console.log(person?.name) // 옵션 체이닝 연산자를 사용해 런타임 오류 없이 정상 실행되며 undefined 값 반환
```

옵션 체이닝 연산자는 '세이프 내비게이션 연산자(safe navigation operator)'라고 하는데, 이유는 다음 예시와 같다.
```ts
let person
let longitude = person?.location?.coords?.longitude // 2) safe navigation 연산자를 사용하여 간결히 구현
console.log(longitude)
if (person && person.location && person.location.coords) { // 1) 이런식으로 긴 코드를
    longitude = person.location.coords.longitude
}
```

## 널 병합 연산자
- 널 병합 연산자(`??`) 예시는 다음과 같다.
- 옵션 체이닝 연산자 부분이 `undefined`가 되면 널 병합 연산자가 동작해 `undefined` 대신 0을 반환한다.
```ts
let person: IPerson
let longitude = person?.location?.coords?.longitude ?? 0
console.log(longitude)
```

## nullable 타입의 함수형 방식 구현
- 함수형 프로그래밍 언어인 하스켈에는 Maybe란 타입이 있고, 스칼라 언어는 Maybe 타입의 이름을 Option으로 바꿔서 제공한다.
- 다른 언어들도 Option 혹은 Optional 이라는 이름으로 이 타입을 제공한다.
```ts
interface IValuable<T> {
    getOrElse(defaultValue: T)
}
// 함수형 프로그래밍 언어에서 map이라는 메서드가 있는 타입들을 펑터(functor)라고 부른다.
interface IFunctor<T> {
    map<U>(fn: (value: T) => U)
}
```

### Some 클래스 구현
```ts
class Some<T> implements IValuable<T>, IFunctor<T> {
    constructor(private value: T) {} // value 속성이 private 이므로
    getOrElse(defaultValue: T) { // 이 메서드를 통해 Some 클래스에 담긴 값을 얻어야 한다.
        return this.value ?? defaultValue
    }
    map<U>(fn: (T) => U) { // value 값을 변경하려면 항상 이 메서드를 사용해야 한다.
        return new Some<U>(fn(this.value))
    }
}
```

### None 클래스 구현
```ts
class None implements IValuable<nullable>, IFunctor<nullable> {
    getOrElse<T>(defaultValue: T | undefined) {
        return defaultValue
    }
    map<U>(fn: (T) => U) { // 이 메서드는 콜백 함수를 사용하지 않는데, None 클래스는 nullable 타입 값을 의미하므로, nullable 타입 값들이 콜백 함수에서 동작하면 프로그램이 비정상 종료되기 때문
        return new None
    }
}
```

### Some과 None 클래스 사용
```ts
// 해당 클래스는 스칼라에서 사용되는 방식으로 동작
class OptionT {
    // 생성자가 private으로 선언되어 new 연산자로 인스턴스 생성 불가하며 정적 메서드 Option.Some(값) 혹은 정적 속성 Some.None 형태로만 생성 가능
    private constructor() {}
    static Some<T>(value: T) {
        return new Some<T>(value)
    }
    static None = new None()
}

let m = OptionT.Some(1)
let value = m.map(value => value + 1).getOrElse(1)
console.log(value) // 2

let n = OptionT.None
value = n.map(value => value + 1).getOrElse(0)
console.log(value) // 0
```

## Option 타입과 예외 처리
- Option 타입은 부수 효과가 있는 불순(impure) 함수를 순수(pure) 함수로 만드는 데 효과적이다.
- 자바스크립트의 parseInt는 문자열을 수로 만들어주는 데, 숫자형 문자열이 아닌 경우 NaN(Not a Number) 값을 만든다.
- 다음 함수는 자바스크립트가 제공하는 NaN 여부를 체크하는 isNaN 함수를 사용하여 OptionT 타입 값을 반환한다.
```ts
const parseNumber = (n: string): IFunctor<number> & IValuable<number> => {
    const value = parseInt(n)
    return isNaN(value) ? OptionT.None : OptionT.Some(value)
}
```

- 자바스크립트의 JSON.parse 함수는 매개변수가 정상적인 JSON 포맷 문자열이 아니면 예외를 발생시킨다.
- 예외를 발생시키는 함수는 부수 효과가 있는 불순 함수지만, try/catch 문과 Option을 활용해 순수 함수가 되었다.
```ts
const parseJson = <T>(json: string): IValuable<T> & IFunctor<T> => {
    try {
        const value = JSON.parse(json)
        return OptionT.Some<T>(value)
    } catch (e) {
        return OptionT.None
    }
}
```
