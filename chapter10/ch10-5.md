# 10-5. F-바운드 다형성

## this 타입과 F-바운드 다형성
- 타입스크립트에서 `this` 키워드는 타입으로도 사용된다.
- `this`가 타입이 되면 객체지향의 다형성 효과가 나는데, 일반적인 다형성과 구분하기 위해 `this` 타입으로 인한 다형성을 'F-바운드 다형성(F-bound polymorphism)'이라고 한다.

### F-바운드 타입
자신을 구현하거나 상속하는 서브타입(subtype)을 포함하는 타입
```ts
// 자신을 상속하는 타입이 포함되어 있지 않은 일반 타입
interface IValueProvider<T> {
    value(): T
}
// add 메서드가 나를 상속하는 타입을 반환하는 F-바운드 타입
interface IAddable<T> {
    add(value: T): this
}
interface IMultiplyable<T> {
    multiply(value: T): this
}
```

### `IValueProvider<T>`, `IAddable<T>`, `IMultiplyable<T>` 인터페이스 구현
```ts
class Calculator implements IValueProvider<number>, IAddable<number>, IMultiplyable<number> {
    constructor(private _value: number = 0) {}
    // private으로 만들어 _value 속성을 value() 메서드를 통해 접근할 수 있게 구현
    value(): number {
        return this._value
    }
    // this를 반환함으로써 메서드 체인 기능 구현
    add(value: number): this {
        this._value = this._value + value
        return this
    }
    multiply(value: number): this {
        this._value = this._value * value
        return this
    }
}

const value = (new Calculator(1))
                .add(2)
                .add(3)
                .multiply(4)
                .value() // 메서드 체인을 위한 것이 아닌, _value 값을 가져오는 것이 목적이므로, 가장 마지막에 호출
console.log(value)
```
```ts
class StringComposer implements IValueProvider<string>, IAddable<string>, IMultiplyable<number> {
    constructor(private _value: string = '') {}
    value(): string {
        return this._value
    }
    add(value: string): this {
        this._value = this._value.concat(value)
        return this
    }
    multiply(repeat: number): this {
        const value = this.value()
        for(let index = 0; index < repeat; index++) {
            this.add(value)
        }
        return this
    }
}

const value = new StringComposer('hello')
                    .add(' ')
                    .add('world')
                    .add('!')
                    .multiply(3)
                    .value()
console.log(value)
```
- `IAddable<T>`의 add 메서드나 `IMultiplyable<T>`의 multiply 메서드는 구현체에 따라 반환 타입이 Calculator가 되거나 StringComposer가 되기도 한다.
- 즉, 반환 타입 this는 Calculator가 되거나 StringComposer가 되기도 하는데, 이런 동작 방식을 'F-바운드 다형성' 이라고 한다.
