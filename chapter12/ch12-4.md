# 12-4. 리액트와 부트스트랩으로 프런트엔트 웹 만들기

- API 서버는 JSON 포맷의 데이터만 보내주므로, 웹브라우저에서 자바스크립트가 동작해 동적으로 HTML을 만들어 주어야 한다.
- 웹 브라우저에서 이러한 방식으로 동작하는 웹 서비스를 '프런트엔드 웹(frontend web)'이라고 한다.
- 과거에는 프런트엔드 웹 개발 시 jQuery를 많이 사용했지만, 지금은 React.js와 같은 프런트엔드 프레임워크를 사용하는 추세이다.

---
- 리액트의 소스코드는 `src` 디렉터리 아래에 있어야 한다.
- 리액트 프로젝트는 항상 `src` 디렉터리에 `App.tsx`라는 이름의 파일이 있다.
```tsx
import React from 'react'

const App: React.FC = () => {
    const user = { name: 'Jack', age: 32 }
    return (
        <div className='App'>{
            JSON.stringify(user)
        }</div>
    )
}
```

## JSX란?
- JSX(JavaScript XML)는 페이스북이 만든 간단한 프로그래밍 언어이다.
- JSX 언어는 자바스크립트의 확장 기능 형태로 동작한다. 아래 예시가 JSX 부분 이다.
```tsx
<div className='App'>{
    JSON.stringify(user)
}</div>
```
- 보통 JSX 코드가 있는 자바스크립트 파일은 확장자 `.jsx`를 사용한다.
- 그런데 개발 언어가 타입스크립트인 경우 `.tsx`를 사용한다.
- JSX 코드가 있는 파일은 반드시 첫 줄에 React라는 심벌을 import해야 한다.

## 컴포넌트란?
- 리액트가 컴포넌트라고 부르는 함수는 반환값으로만 사용할 수 있다.
- 다음 코드에서 App이 컴포넌트의 한 예인데, 이 함수는 JSX 코드를 반환한다.
- 보통 JSX 코드는 컴파일러는 혼란스럽게 하지 않도록 소괄호 기호 `()`로 감싸준다.
```ts
const App: React.FC = () => {
    return (
        <div className='App'></div>
    )
}
```

## useState 함수 사용하기
- 서버에서 수신한 값을 컴포넌트에서 사용하려면 useState 함수를 사용한다.
- useState 함수는 배열에 적용한 비구조화 할당 구문을 사용해 데이터 users와 setUsers 함수를 얻게 해준다. useState의 입력 매개변수인 빈 배열 []은 users에 초깃값으로 사용된다.
    - users와 setUsers와 같은 함수 이름은 개발자가 마음대로 지을 수 있다.
```ts
import { useState } from 'react'

const [users, setUsers] = useState<IUser []>([])
```

## useEffect 함수 사용하기
useEffect 함수를 사용하면 웹 브라우저 화면은 바뀌지 않지만, App 컴포넌트가 처음 그려질 때(렌더링될 때) 딱 한 번만 실행된다.
```ts
import React, { useState, useEffect } from 'react'
import { IUser } from './IUser'
import { getDataPromise } from './getDataPromise'

const App: React.FC = () => {
    const [users, setUsers] = useState<IUser[]>([])

    useEffect(() => {
        getDataPromise((receivedUsers: IUser[]) => {
            setUsers([...users, ...receivedUsers])
        })(0, 1)
    }, [])

    return (
        <div className='App'>{JSON.stringify(user)}</div>
    )
}
```
