# 12-2. 몽고DB에 데이터 저장하기

- 데이터베이스
    - 관계형 데이터 베이스 시스템
        - SQL이라는 데이터 질의 언어를 사용
        - '테이블(table)'을 만들고 관련된 데이터를 저장하는데, 테이블에 저장하는 한 개의 데이터를 '레코드(record)'라고 한다.
    - NoSQL(Non SQL) 데이터베이스 시스템
        - 이름 그대로 SQL을 사용하지 않고 다른 방식의 질의어를 사용
        - 테이블이라는 용어 대신에 '컬렉션(collection)'을 사용하고, 레코드 대신 '문서(document)'라고 한다.
