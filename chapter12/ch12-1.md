# 12-1. 빅데이터 배치 프로그램 만들기

- 자바스크립트나 타입스크립트는 파일에 데이터를 저장할 때 주로 JSON 포맷을 사용한다.
- 그런데 저장할 데이터의 분량이 많아지면 JSON 파일 포맷은 시스템 메모리를 많이 사용한다. 예를 들어, 1000만 건의 데이터가 담긴 JSON 파일을 읽는다면, JSON 포맷의 물리적인 구조상 이 데이터를 한꺼번에 읽어들여야 한다.
- 데이터를 파일에 저장할 때는 JSON처럼 나중에 읽기 쉬운 형식으로 만든다. 보통 형태의 데이터는 파일 확장자가 `.csv`인 파일에 저장한다.
- CSV 파일 형식의 가장 큰 장점은 맨 첫 줄의 헤더 정보에 데이터를 나타내는 이름을 쉽표(`,`)로 구분해 놓으면, 그 다음 줄부터는 각 이름에 해당하는 데이터를 똑같이 쉼표로 구분해 놓을 수 있다는 점이다. 예를 들어, 1000만 명의 고객정보를 1000만 줄 + 헤더 1줄로 쉽게 나타낼 수 있다.
- 또한, CSV 파일 형식은 데이터를 한꺼번에 읽지 않고 한 줄씩 읽는다. JSON은 파일을 전부 읽지 않고서는 데이터의 의미를 파악할 수 없다. 그러나 CSV 평식은 맨 첫 줄을 읽어 쉼표로 구분된 항목의 의미를 파악한 다음, 파일의 끝까지 한 줄씩 계속 데이터를 읽어서 시스템 자원을 적게 소비한다.

---

- 객체 object를 JSON 문자열로 바꿔주는 기능인 `JSON.stringify(object)`
- 반면에, `JSON.stringify(object, null, 2)`는 줄 바꿈도 하고 들여쓰기도 해주어, 사람이 읽기 편한 형태의 JSON 문자열을 만들어 준다. 여기서 숫자 2는 들여쓰기를 위해 공백 문자를 2개 사용한다는 의미이다.

---

- 파일에 담긴 데이터는 텍스트 포맷으로 읽을 수도 있고 바이너리 포맷으로 읽을 수도 있다.
    - 텍스트 포맷
        - 영문으로만 이루어졌다고 가정하는 ANSI 포맷
        - 비영어권 문자도 있다고 가정하는 유니코드 포맷
            - ANSI 문자열 체계를 확장한 utf8 포맷
            - 원래의 유니코드 포맷
- 파일을 읽거나 쓸 때는 기본적으로 utf8 포맷을 사용한다.
