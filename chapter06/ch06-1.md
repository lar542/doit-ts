# 06-1. 반복기 이해하기

for...of 구문은 배열에 담긴 값을 차례로 순회하는데, 이는 다른 프로그래밍 언어에서도 '반복기(iterator)'라는 주제로 흔히 찾아볼 수 있다.
대부분 프로그래밍 언어에서 반복기는 다음과 같은 특징이 있는 객체이다.
- next 라는 이름의 메서드를 제공한다
- next 메서드는 value와 done이라는 2개의 속성을 가진 객체를 반환한다.

다음 예시의 createRangeIterable 함수는 next 메서드가 있는 객체를 반환하므로 이 함수는 반복기를 제공하는 역할을 한다.
```ts
// iterator를 제공하는 반복기 제공자(iterable)
export const createRangeIterable = (from: number, to: number) => {
    let currentValue = from
    return {
        next() {
            const value = currentValue < to ? currentValue++ : undefined
            const done = value == undefined
            return { value, done }
        }
    }
}
```

- 2행에서 createRangeIterable 함수를 호출해 반복기를 얻고 iterator 변수에 저장한다. 반복기는 이처럼 반복기 제공자를 호출해야만 얻을 수 있다.
- 3~7행은 반복기를 사용하는 코드 이다. true로 반환할 때까지 iterator 변수의 next 메서드를 반복 호출하면서 반복기 제공자가 제공하는 value 값을 얻는다.
- 참고로 사용자가 타입스크립트로 for...of 구문을 작성하면 TSC 컴파일러는 이처럼 반복기 제공자와 반복기를 사용하는 코드로 바꿔준다.
```ts
const createRangeIterableTest = () => {
    const iterator = createRangeIterable(1, 3 + 1) // iterator는 현재 동작하지 않는다
    while (true) {
        const { value, done } = iterator.next() // iterator를 동작시킨다
        if (done) break
        console.log(value)
    }
}
```

## 반복기는 왜 필요한가?
반복기 제공자는 이처럼 어떤 범위의 값을 한꺼번에 생성해서 배열에 담지 않고 값이 필요할 때만 생성한다. <br>
즉, 다음의 range 함수처럼 값이 필요한 시점보다 이전에 미리 생성하는 것 보다 createRangeIterable 함수는 값이 필요한 시점에 비소로 생성한다는 점에서 시스템 메모리를 훨씬 적게 소모한다.
```ts
const range = (from, to) => from < to ? [from, ...range(from + 1, to)]: []
```

## for...of 구문와 [Symbol.iterator] 메서드
- 다음과 같이 for...of 구문을 적용하려면 RangeIterable 클래스처럼 클래스로 구현하고 [Symbol.iterator] 메서드를 구현해야 한다.
- 참고로 클래스의 메서드는 자바스크립트의 function 키워드가 생략되었을 뿐 사실상 function 키워드로 만들어진 함수이다. 그런데 function 키워드로 만들어지는 함수는 내부에서 this 키워드를 사용할 수 있다. 다음 코드에서 this를 that 변수에 담고 있는데, 이것은 that.to 부분을 위한 것이다. next 함수 또한 function 키워드가 생략된 메서드이기 때문에 컴파일러가 next의 this로 해석하지 않기 위한 코드 트릭 이다.
```ts
export class RangeIterable {

    constructor(public from: number, public to: number) {}

    [Symbol.iterator]() {
        const that = this
        let currentValue = that.from
        return {
            next() {
                const value = currentValue < that.to ? currentValue++ : undefined
                const done = value == undefined
                return { value, done }
            }
        }
    }
}

const rangeIterableTest = () => {
    const iterator = new RangeIterable(1, 3 + 1)

    for (let value of iterator)
        console.log(value)
}
```

## `Iterable<T>`와 `Iterator<T>` 인터페이스
- 타입스크립트는 반복기 제공자에 `Iterable<T>`와 `Iterator<T>` 제네릭 인터페이스를 사용할 수 있다.
    - `Iterable<T>` : 해당 구현체가 `[Symbol.iterator]` 메서드를 제공한다는 것을 명확하게 알려주는 역할
    - `Iterator<T>` : 반복기가 생성할 값의 타입을 명확하게 해준다.
```ts
class 구현 클래스 implements Iterable<생성할 값의 타입> {}

[Symbol.iterator](): Iterator<생성할 값의 타입> {}
```

```ts
export class StringIterable implements Iterable<string> {

    constructor(public strings: string[] = [], private currentIndex: number = 0) {}

    [Symbol.iterator](): Iterator<string> {
        const that = this
        let currentIndex = that.currentIndex, length = that.strings.length

        const iterator: Iterator<string> = {
            next(): IteratorResult<string> {
                if (currentIndex < length) {
                    return { value: that.strings[currentIndex++], done: false }
                }
                return { value: undefined, done: true }
            }
        }

        return iterator
    }

}
```
