# 06-2. 생성기 이해하기

- ESNext 자바스크립트와 타입스크립트에서 제공하는 `yield` 키워드는 마치 return 키워드처럼 값을 반환한다.
- `yield`는 반드시 `function*` 함수 안에서만 호출할 수 있으며, 이러한 함수를 '생성기(generator)'라고 한다.
- 다음 예시에서 6행은 `yield` 문을 3회 반복해서 호출하도록 구현되었다.
```ts
function* generator() {
    console.log('generator started...')

    let value = 1
    while(value < 4)
        yield value++

    console.log('generator finished...')
}

const generatorTest = () => {
    for (let value of generator())
        console.log(value)
}
```

## setInterval 함수와 생성기의 유사성
- 생성기(generator)가 동작하는 방식을 '세미코루틴(semi-coroutine, 반협동 루틴)' 이라고 한다.
- 이는 타입스크립트처럼 single-thread로 동작하는 프로그래밍 언어가 마치 multi-thread로 동작하는 것처럼 보이게 하는 기능을 말한다.
- 코루틴은 애플리케이션 레벨의 스레드 인데, 스레드는 원래 운영체제가 제공하는 개수가 제한된 서비스이다. 운영체제에 부담을 주지 않으면서 애플리케이션에서 스레드를 마음껏 쓸 수 있게 하는 것이 코루틴의 목적이다. 그런데 코루틴은 스레드이므로 일정 주기에 따라 자동으로 반복해서 실행된다. 반면에 생성기는 절반만 코루틴이다. 즉, 반복해서 실행할 수 있지만 자동으로 실행되지 못하는 코루틴이다. 생성기는 사용하는 쪽 코드에서 생성기가 만들어 준 반복자의 next 메서드가 호출될 때만 한 번 실행된다. 만약, next 메서드가 while 문에서 반복해서 호출된다면, 생성기는 next 호출 때 한 번 실행되고 곧바로 멈춘다. 이처럼 생성기는 자동으로 반복 실행되지 않으므로 세미코루틴이라고 한다.

## function* 키워드
generator는 `function*` 키워드로 선언해야 하므로 화살표 함수로는 만들 수 없으며, iterator를 제공하는 iterable로서 동작한다.

## yield 키워드
`yield`는 연산자(operator) 형태로 동작하며, iterator를 자동으로 만들어주고, iterable 역할도 수행한다.
```ts
function* rangeGenerator(from: number, to: number) {
    let value = from
    while(value < to) {
        yield value++
    }
}

const rangeGeneratorTest = () => {
    // while 패턴으로 동작하는 생성기
    const iterator = rangeGenerator(1, 3 + 1)
    while(1) {
        const { value, done } = iterator.next()
        if (done) break
        console.log(value)
    }

    // for...of 패턴으로 동작하는 생성기
    for (let value of rangeGenerator(4, 6 + 1))
        console.log(value)
}
```

## 반복기 제공자의 메서드로 동작하는 생성기 구현
generator는 iterable로서 동작하기 때문에 StringIterable 클래스를 generator 방식으로 구현하면 다음과 같이 간결하게 구현할 수 있다.
```ts
class IterableUsingGenerator<T> implements Iterable<T> {

    constructor(public values: T[] = [], private currentIndex: number = 0) {}

    // generator를 클래스 메서드의 몸통이 되게 하려면 반드시 아래와 같이 정의해야 한다.
    // [Symbol.iterator] = function* () { => ES6 초창기 : 프로퍼티에 제너레이터 함수를 할당
    *[Symbol.iterator](): Generator<T> { // 최신 표준 : 제너레이터 메서드 선언
        while(this.currentIndex < this.values.length)
            yield this.values[this.currentIndex++]
    }
}

const iterableUsingGeneratorTest = () => {
    for (let value of new IterableUsingGenerator([1, 2, 3]))
        console.log(value)

    for (let value of new IterableUsingGenerator(['hello', 'world', '!']))
        console.log(value)
}
```

## yield* 키워드
`yield`는 단순히 값을 대상으로 동작하지만, `yield*`는 다른 generator나 배열을 대상으로 동작한다.
```ts
function* gen12() {
    yield 1
    yield 2
}

function* gen12345() {
    yield* gen12()
    yield* [3, 4]
    yield 5
}

const gen12345Test = () => {
    for (let value of gen12345())
        console.log(value)
}
```

## yield 반환값
- yield 연산자는 값을 반환한다.
- 다음 코드에서 yield 연산자의 반환 값을 select 변수에 저장하고 있다.
- yield 연산자의 반환 값은 iterator의 next 메서드 호출 때 매개변수에 전달하는 값이다.
- 코드를 실행하면 첫 줄 외에 다른 줄은 모두 난수가 출력된다. 이는 select 변수를 0으로 설정했기 때문 이다. 실행 결과는 이전 next 메서드가 전달한 값이 다시 gen 함수의 내부 로직에 의해 현재의 value 값이 되어 출력된다.
```ts
function* gen() {
    let count = 5
    let select = 0
    while(count--) {
        console.log('현재 select : ', select)
        select = yield `you select ${select}`
        console.log('세팅 select : ', select)
    }
}

const random = (max, min = 0) => Math.round(Math.random() * (max-min)) + min

const genTest = () => {
    const iterator = gen()

    while (true) {
        const { value, done } = iterator.next(random(10, 1))
        if (done) break
        console.log('전달 : ', value)
    }
}
```
