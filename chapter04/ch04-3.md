# 04-3. 화살표 함수와 표현식 문

- ESNext 자바스크립트와 타입스크립트는 화살표 함수도 제공한다.
- 그런데 화살표 함수의 몸통은 function 때와 달리 중괄호를 생략할 수도 있다.
- 중괄호 사용 여부에 따라 타입스크립트 문법이 동작하는 방식이 실행문(execution statement, 보통 줄여서 statement) 방식과 표현식 문(expression statement) 방식으로 달라진다.
```ts
const arrow1 = (a: number, b: number): number => { return a + b } // 실행문 방식 몸통
const arrow2 = (a: number, b: number): number => a + b // 표현식 문 방식 몸통
```

## 실행문과 표현식 문
- 오래전부터 프로그래밍 언어는 실행문 지향 언어와 표현식 지향 언어로 구분되어 왔다.
- 자바스크립트 ES5는 실행문 지향 언어지만, ESNext와 타입스크립트는 실행문과 표현식 문을 동시에 지원한다. = 다중 패러다임 언어(multi-paradigm language)
- 프로그래밍 언어에서 실행문 = CPU에서 실행되는 코드
- 그런데 실행문은 CPU에서 실행만 될 뿐 결과를 알려주지 않는다. 실행문의 실행 결과를 알려면 반드시 return 키워드를 사용해야 한다.
- 반면에 표현식 문은 CPU에서 실행된 결과를 굳이 return 키워드를 사용하지 않아도 알려준다.
- 다음처럼 변수에 값을 대입하는 것은 대표적인 실행문이다.
```js
let x
x = 1
```
반면에 다음과 같이 `x > 0` 부분은 CPU가 평가한 후 값으로 결과를 알려주지 않으면 if문이 정상적으로 동작할 수 없다.
```js
let x = 10
if (x > 0)
    x = 1
```
그런데 만일 프로그래밍 문법이 다음과 같다면 코드 작성이 번거로워진다.
```js
if (return x > 0)
    x = 1
```
즉, 똑같이 CPU에서 실행되는 구문이더라도 `x > 0`처럼 return 키워드 없이 결과값을 반환하는 실행문이 필요하다. 이를 '표현식 문(expression statement)'이라고 구분해서 부른다.

## 복합 실행문
프로그래밍 언어에서 if 같은 구문은 조건을 만족하면 단순히 한 줄의 실행문만을 실행하는 형태로 설계한다.
```js
if (조건식)
    실행문
```
- 이런 설계가 가능한 이유는 복합 실행문(compound statement)이라는 형태를 함께 제공하기 때문이다.
- 복합 실행문은 중괄호 `{}`를 사용해서 컴파일러로 하여금 여러 실행문을 1개처럼 인식하게 한다.
```js
if (조건식) {
    실행문1
    실행문2
}
```

## 함수 몸통과 복합 실행문
- function 키워드로 만든 함수는 반드시 몸통을 중괄호 `{}`로 감싸야 하는데, 이는 앞서 설명한 복합 실행문을 의미한다.
- 참고로 복합 실행문 안의 변수의 유효 범위도 지역 범위(local scope)로 제한되기 때문에 각 함수 몸통에서만 유효하다.
```js
function f() {
    let x = 1, y = 2
    let result = x + y + 10
}
```

## return 키워드
- 앞서 설명한 대로 실행문은 CPU에서 실행된 결과를 알려주지 않는다.
- 다음과 같이 함수 몸통을 복합 실행문으로 구현한 함수는 결과를 반환하지 않는다.
```ts
function isGreater(a: number, b: number): boolean {
    a > b
}
```
실행문 기반 언어는 이를 해결하기 위해 return 이라는 키워드를 도입했다.
```ts
function isGreater(a: number, b: number): boolean {
    return a > b
}
```
- 그런데 return 키워드는 반드시 함수 몸통에서만(복합 실행문 안에서만) 사용할 수 있다는 제약이 있다.
- 이러한 제약은 문법을 잘못 이해해 다음과 같은 코드를 만드는 것을 방지하려는 의도이다.
```js
if (return x > 0) x = 1
```

## 표현식 문 스타일의 화살표 함수 구현
앞서 function 스타일 함수를 화살표 함수로 구현하면 다음과 같다.
```ts
const isGreater = (a: number, b: number): boolean => {
    return a > b
}
```
- 이런 단순한 내용을 구현하는 것은 번거로워서 ESNext와 타입스크립트는 다음과 같이 구현할 수 있게 한다.
- 즉, 함수 몸통이 표현식으로 구현되었다. 표현식은 값을 반환하는 실행문이므로 return 키워드 또한 생략되었다.
```ts
const isGreater = (a: number, b: number): boolean => a > b
```

## 표현식과 표현식 문의 차이
- 2행의 `a > b` 코드는 C 언어에서 '표현식'이라고 했기 때문에 그 이후 만들어진 프로그래밍 언어들도 C 언어와 같은 의미로 표현식이라고 생각한다.
- 따라서 C 언어 관점에서 실행문의 일부일 뿐 그 자체가 실행문인 것은 아니다.
- 반면에 표현식 지향 언어 관점에서 3행의 `a > b` 코드는 그 자체가 실행문(statement)이다.
- 결론적으로 표현식(expression)이란 용어는 두 가지 형태로 사용되는데, 이 둘을 구분하고자 표현식(expression)과 표현식 문(expression statement)으로 구분한 것이다.
```js
let a = 1, b = 0
if (a > b) console.log('a is greater than b')
const isGreater = (a: number, b: number): boolean => a > b
```

## 실행문을 만드는 세미콜론
- C 언어는 모든 문장이 반드시 세미콜론 `;`으로 끝나야 한다.
- C 언어 구문을 참조해 만든 ES5 자바스크립트 또한 모든 문장 끝에 세미콜론이 있어야 한다.
- 반면에 ESNext 자바스크립트와 타입스크립트에서는 세미콜론을 생략할 수 있다.
- 다만, 타입스크립트에서는 관습적으로 표현식 문에는 세미콜론을 붙이지 않는다.
