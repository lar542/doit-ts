# 07-3. async와 await 구문

## await 키워드
- 피연산자(operand)의 값을 반환한다.
- 만약, 피연산자가 Promise 개체면 then 메서드를 호출해 얻은 값을 반환한다.

## async 함수 수정자
- await 키워드는 항상 async가 붙은 함수 수정자(function modifier)가 있는 함수 몸통에서만 사용할 수 있다.
- async 함수는 일반 함수처럼 사용할 수 있으며, Promise 객체로 사용할 수 있다.
```ts
const test1 = async () => {
    let value = await 1
    console.log(value)
    value = await Promise.resolve(1)
    console.log(value)
}
async function test2() {
    let value = await 'hello'
    console.log(value)
    value = await Promise.resolve('hello')
    console.log(value)
}

// 일반 함수처럼 호출
test1()
test2()

// async 함수를 Promise 객체로 사용
test1().then(() => test2())
```

## async 함수가 반환하는 값의 의미
async 함수는 값을 반환할 수 있는데, 이때 반환 값은 Promise 형태로 변환되므로 다음처럼 then 메서드를 통해 반환 값을 얻어야 한다.
```ts
const asyncReturn = async () => {
    return [1, 2, 3]
}
asyncReturn().then(value => console.log(value))
```

## async 함수의 예외 처리
만약 예외가 발생한다면 프로그램이 비정상 종료되므로, 반드시 catch 메서드를 호출하는 형태로 작성해야 한다.
```ts
const asyncException = async () => {
    throw new Error('error')
}
asyncException().catch(error => console.log('error : ', error.message))
```

만약 await 구문에서 Promise.reject 값이 발생한다면, 마찬가지로 프로그램이 비정상 종료하므로 catch 메서드를 호출해야 한다.
```ts
const awaitReject = async () => {
    await Promise.reject(new Error('error'))
}
awaitReject().catch(error => console.log(' error : ', error.message))
```

## async 함수의 Promise.all
- 다음은 Promise로 만든 readFilePromise 함수를 async 함수에 적용했다.
- Promise.all 메서드로 단일 Promise 객체로 만든 결과를 await 구문을 적용해 resolve된 값을 반환한다.
```ts
const readFilesAll = async (filenames: string[]) => {
    return await Promise.all(
        filenames.map(filename => readFilePromise(filename))
    )
}

// readFilesAll 함수를 Promise 객체로 취급해 then, catch 메서드로 then-chain 형태로 연결
readFilesAll(['./package.json', './tsconfig.json'])
    .then(([packageJson, tsconfigJson]: string[]) => {
        console.log('<package.json>: ', packageJson)
        console.log('<tsconfig.json>: ', tsconfigJson)
    })
    .catch(error => console.log('error : ', error.message))
```
