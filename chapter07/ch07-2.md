# 07-2. Promise 이해하기

- 자바스크립트에서 프로미스는 ES5 버전에서 정식 채택되었고, 프로미스는 Promise라는 클래스 이다.
- 따라서 new 연산자를 통해 Promise 객체를 만들어 사용해야 한다.
- 그리고 Promise 객체를 만들 때 콜백 함수를 제공해야 하는데, 해당 콜백 함수는 resolve와 reject라는 2개의 매개변수를 가지며, 둘 다 함수이다.
- 타입스크립트에서 Promise는 제네릭 클래스 형태로 사용한다.
- 아래는 비동기 API인 readFile을 호출하는 내용을 프로미스로 구현한 예시 이다.
```ts
import { readFile } from 'fs'

const readFilePromise = (filename: string): Promise<string> =>
    new Promise<string>((
        resolve: (value: string) => void, 
        reject: (error: Error) => void
    ) => {
        readFile(filename, (error, buffer) => {
            if (error) reject(error) // 에러 발생 시 reject 함수 호출
            else resolve(buffer.toString()) // 정상 실행 시 resolve 함수 호출
        })
    })
```

- 다음은 readFilePromise 함수가 반환하는 Promise 객체의 메서드를 메서드 체인 형태로 사용하고 있다.
- readFilePromise 함수에서 resolve 함수를 호출한 값은 then 메서드의 콜백 함수로 전달되고, reject 함수를 호출한 값은 catch 메서드의 콜백 함수로 전달된다.
```ts
readFilePromise('./package.json')
    .then((content: string) => {
        console.log('1---------------')
        console.log(content) // package.json 파일을 읽은 내용
        return readFilePromise('./tsconfig.json')
    })
    .then((content: string) => {
        console.log('2---------------')
        console.log(content) // tsconfig.json 파일을 읽은 내용
        return readFilePromise('.') // catch 콜백 함수로 발생하는 오류를 전달
    })
    .catch((error: Error) => console.log('error : ', error.message))
    .finally(() => console.log('프로그램 종료'))
```

## Promise.resolve 메서드
- Promise 클래스가 제공하는 클래스 메서드(정적 메서드)인 resolve 메서드가 있다.
- 앞에서 Promise 객체 생성 시 resolve 함수를 호출했는데, Promise.resolve는 이를 클래스 메서드로 구현한 것이다.
- 해당 형태로 호출하면 항상 결과는 then 메서드에서 얻을 수 있다.
```ts
Promise.resolve(1)
    .then(value => console.log(value))

Promise.resolve('hello')
    .then(value => console.log(value))

Promise.resolve([1, 2, 3])
    .then(value => console.log(value))

Promise.resolve({ name: 'Jack', age: 32 })
    .then(value => console.log(value))
```

## Promise.reject 메서드
마찬가지로 클래스 메서드인 reject도 호출하면 항상 catch 메서드의 콜백 함수에서 얻을 수 있다.
```ts
Promise.reject(new Error('에러 발생'))
    .catch((error: Error) => console.log('error : ', error.message))
```

## then-체인
- Promise의 then 인스턴스 메서드 호출 시 사용한 콜백 함수는 값을 반환할 수 있다.
- then에서 반환된 값은 또 다른 then 메서드에서 호출해 값을 수신할 수 있다.
- then 메서드는 반환된 값이 Promise 타입이면 이를 resolve한 값을 반환한다.
- 만약 reject된 값일 경우 catch 메서드에서 이 값을 받을 수 있다.
- then 메서드를 여러 번 호출하는 형태를 then-chain 이라고 한다.
```ts
Promise.resolve(1)
    .then((value: number) => {
        console.log(value)
        return Promise.resolve(true)
    })
    .then((value: boolean) => {
        console.log(value)
        return [1, 2, 3]
    })
    .then((value: number[]) => {
        console.log(value)
        return { name: 'Jack', age: 32 }
    })
    .then((value: { name: string, age: number }) => {
        console.log(value)
    })
```

## Promise.all 메서드
Array 클래스는 every 라는 인스턴스 메서드를 제공하는데, 이는 배열의 모든 요소가 조건을 만족하면 true를 반환한다.
```ts
const isAllTrue = (values: boolean[]) => values.every((value => value == true))

console.log(isAllTrue([true, true, true]))  // true
console.log(isAllTrue([false, true, true])) // false
```

- every와 비슷하게 Promise 클래스는 all 이라는 클래스 메서드를 제공한다.
- 이는 Promise 객체들을 배열로 받아, 모든 객체를 대상으로 resolve된 값들의 배열로 만들어주는데, 이를 또 다른 Promise 객체로 감싸 반환하므로 resolve된 값들의 배열은 then 메서드에서 얻어야 한다.
- 만약, 배열에 담긴 Promise 객체 중 reject 객체가 발생하면, 더 기다리지 않고 해당 reject value를 담은 Promise.reject 객체를 반환하고 해당 값은 catch 메서드에서 얻을 수 있다.
```ts
const getAllResolveResult = <T>(promises: Promise<T>[]) => Promise.all(promises)

getAllResolveResult<any>([
    Promise.resolve(true),
    Promise.resolve('hello')
]).then(result => console.log(result))

getAllResolveResult<any>([
    Promise.reject(new Error('error')),
    Promise.resolve(1)
])
.then(result => console.log(result)) // 호출되지 않는다.
.catch(error => console.log('error : ', error.message))
```

## Promise.race 메서드
Array 클래스는 배열의 요소 중 하나라도 조건을 만족하면 true를 반환하는 some 인스턴스 메서드를 제공한다.
```ts
const isAnyTrue = (values: boolean[]) => values.some((value => value == true))

console.log(isAnyTrue([false, true, false]))    // true
console.log(isAnyTrue([false, false, false]))   // false
```

- 마찬가지로 비슷한 Promise.race 클래스 메서드는 배열에 담긴 Promise 객체 중 하나라도 resolve되면 이 값을 담은 Promise.resolve 객체를 반환한다.
- 만약, reject 값이 가장 먼저 발생하면 Promise.reject 객체를 반환한다.
```ts
Promise.race([
    Promise.resolve(true), 
    Promise.resolve('hello')
]).then(value => console.log('success : ', value))

Promise.race([
    Promise.resolve(true), 
    Promise.reject(new Error('hello'))
])
.then(value => console.log('success : ', value))
.catch(error => console.log('error : ', error.message)) // 호출되지 않는다.

Promise.race([
    Promise.reject(new Error('hello')),
    Promise.resolve(true)
])
.then(value => console.log('success : ', value)) // 호출되지 않는다.
.catch(error => console.log('error : ', error.message))
```
- Promise는 비동기 API 사용에서 나타나는 콜백 지옥 코드를 어느 정도 관리할 수 있는 형태로 바꿔준다.
- 그러나 ESNext 자바스크립트와 타입스크립트는 Promise를 좀 더 쉬운 형태로 만들 수 있게 하는 [async/await 구문](../chapter07/ch07-3.md)을 제공한다.
