# 07-1. 비동기 콜백 함수

- nodejs는 fs 패키지에 같은 기능을 동기, 비동기 버전으로 나누어 제공한다.
- 운영체제가 제공하는 서비스를 API라고 하며, API는 프로그래밍 언어에서 함수 형태로 제공된다.
- 그런데 API 함수는 실행 시 물리적인 시간이 소요된다.
- 따라서 모두 처리될 때까지 프로그램의 동작을 잠시 멈추는 동기 방식의 API와 프로그램의 동작을 멈추지 않는 대신 결과를 "콜백 함수"로 얻게 하는 비동기 방식의 API를 제공한다.
- 비동기 API의 콜백 함수 = 비동기 콜백 함수(asynchronous callback function) : API의 물리적인 동작 결과를 수신하는 목적으로만 사용된다.

## readFileSync와 readFile API
- nodejs에서 API 이름이 Sync로 끝나는 것은 모두 동기 방식으로 동작한다.
- 동기 방식 API는 작업 종료될 때까지 프로그램을 일시적으로 멈추게 한다.
```ts
import { readFileSync, readFile } from 'fs'

// 파일을 동기 방식으로 읽기
const readFileSyncTest = () => {
    const buffer: Buffer = readFileSync('./package.json') // 해당 파일을 읽는 동안 코드는 일시적으로 멈춘다.
    const content: string = buffer.toString()
    console.log(content)
}

/**
 * 파일을 비동기 방식으로 읽기
 * 동기 버전과 달리
 * 예외 발생 시 해당 예외를 콜백 함수의 첫 번째 매개변수에 전달하고,
 * 결과는 두 번째 매개변수로 전달된다.
 */
const readFileTest = () => {
    console.log('start!')
    readFile('./package.json', (error, buffer) => {
        console.log('loaded!')
        if (error) throw error // 오류 발생 시 처리 코드
        else {
            const content = buffer.toString()
            console.log(content)
        }
    })
    // 비동기 방식으로 동작하므로, 코드는 멈추지 않고 계속 실행
    console.log('end!')
}
```

## 단일 스레드와 비동기 API
- 자바스크립트는 단일 스레드(single-thread)로 동작하므로 될 수 있으면 동기 API를 사용하지 말아야 한다.
- 타입스크립트도 마찬가지로 ES5 자바스크립트로 변환되어 실행되므로 될 수 있으면 동기 API를 사용하지 말아야 한다.
- 스레드 : CPU가 프로그램을 동작시키는 최소 단위
- 프로세스 : 운영체제에서 프로그램이 실행되고 있는 상태
- 프로세스는 1개의 주 스레드와 여러 개의 작업 스레드를 동작시키는데, 자바스크립트 코드는 항상 1개의 작업 스레드, 즉 단일 스레드에서 동작한다.
- 타입스크립트(혹은 자바스크립트) 코드에서 동기 API가 실행된다면 운영체제는 동기 API의 작업 결과를 함수의 반환 값(return value)으로 돌려주어야 한다.
- 이 때문에 운영체제는 동기 API가 실행된 코드를 일시적으로 멈춘 다음, 또 다른 스레드에서 실제 작업을 실행해 결과를 얻으면 그때서야 비로소 잠시 멈췄던 동기 API를 실행하면서 결괏값을 반환한다.
- 만약, 동기 API를 호출하는 JS 코드가 웹 서버에서 실행되면, 단일 스레드로 동작하는 JS의 물리적인 특징상 웹 서버는 동기 API가 결괏값을 반환할 때까지 일시적으로 멈춘다. 그리고 웹 브라우저에서 웹 서버로 접속이 안 되는 현상이 발생한다.
- 타입스크립트(혹은 자바스크립트)는 이처럼 단일 스레드에서 동작하므로 코드를 작성할 때 항상 비동기 방식으로 동작하는 API를 사용해야 한다.

## 콜백 지옥
- 다음과 같이, 비동기 API를 사용하면 콜백 함수에서 또 다른 비동기 API를 호출하면 코드가 매우 복잡해진다. = 콜백 지옥(callback hell)
- [Promise](../chapter07/ch07-2.md)는 이런 콜백 지옥에 빠진 코드를 좀 더 다루기 쉬운 형태의 코드로 만들려는 목적으로 고안되었다.
```ts
import { readFile } from 'fs'

readFile('./package.json', (error, buffer) => {
    if (error) throw error
    else {
        const content = buffer.toString()
        console.log('1...............')
        console.log(content)

        readFile('./tsconfig.json', (error, buffer) => {
            if (error) throw error
            else {
                const content = buffer.toString()
                console.log('2...............')
                console.log(content)
            }
        })
    }
})
```
