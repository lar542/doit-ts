# 08-3. 고차 함수와 커리

함수에서 매개변수의 개수 = 애리티(arity)

## 고차 함수란?
- 타입스크립트에서 함수는 변수에 담긴 함수 표현식이고, 함수 표현식은 일종의 값이다. 따라서 함수의 반환 값으로 함수를 사용할 수 있다.
- 어떤 함수가 또 다른 함수를 반환하면 그 함수를 고차 함수(high-order function) 라고 한다.
- 이런 관점에서
    - 함수가 아닌 단순히 값을 반환하는 함수 = 1차 함수(first-order function)
    - 1차 함수를 반환하는 함수 = 2차 고차 함수(second-order function)
    - 2차 함수를 반환하는 함수 = 3차 고차 함수(third-order function)
- 함수 호출 연산자`()`를 연속해서 사용하는 걸 커리(curry)라고 한다.
```ts
type FirstOrderFunc<T, R> = (T) => R
type SecondOrderFunc<T, R> = (T) => FirstOrderFunc<T, R>
type ThirdOrderFunc<T, R> = (T) => SecondOrderFunc<T, R>

// 1차 함수
const inc: FirstOrderFunc<number, number> = (x: number): number => x + 1
console.log(inc(1)) // 2

// 2차 함수
const add: SecondOrderFunc<number, number> =
    (x: number): FirstOrderFunc<number, number> =>
    (y: number): number => x + y
console.log(add(1)(2)) // 3

// 3차 함수
const add3: ThirdOrderFunc<number, number> =
    (x: number): SecondOrderFunc<number, number> =>
    (y: number): FirstOrderFunc<number, number> =>
    (z: number): number => x + y + z
console.log(add3(1)(2)(3)) // 6
```

## 부분 적용 함수와 커리
- 고차 함수들은 자신의 차수만큼 함수 호출 연산자를 연달아 사용한다.
- 만약, 자신의 차수보다 함수 호출 연산자를 덜 사용하면 '부분 적용 함수(partially applied function)', 짧게는 '부분 함수(partial function)'라고 한다.

## 클로저
- 고차 함수의 몸통에서 선언되는 변수들은 클로저(colsure)라는 유효 범위를 가진다.
    - 클로저 : 지속되는 유효 범위(persistence scope)
- 타입스크립트는 자유 변수가 있으면 그 변수의 바깥쪽 유효 범위에서 자유 변수의 의미(선언문)을 찾고 코드를 정상으로 컴파일 한다.
- 이처럼 고차 함수가 부분 함수가 아닌 '값'을 발생해야 비로소 자유 변수의 메모리가 해제되는 유효 범위를 '클로저'라고 한다.
```ts
function colsureAdd(x: number): (number) => number {
    return function (y: number): number { // 이 함수의 내부 범위만 볼 때 x는 의미를 알 수 없는 변수 = 자유 변수(free variable)
        return x + y // 클로저
    }
}

const colsureAdd1 = colsureAdd(1) // 변수 x 메모리 유지
const result = colsureAdd1(2) // result에 3을 저장 후 변수 x 메모리 해제
```

클로저는 메모리가 해제되지 않고 프로그램이 끝날 때까지 지속될 수도 있다.
```ts
const makeNames = (): () => string => {
    const names = ['Jack', 'Jane', 'Smith'] // 자유 변수
    let index = 0                           // 자유 변수
    return (): string => {
        if (index == names.length)
            index = 0
        return names[index++]
    }
}
const makeName: () => string = makeNames()
console.log([1, 2, 3, 4, 5, 6].map(n => makeName()))
```
